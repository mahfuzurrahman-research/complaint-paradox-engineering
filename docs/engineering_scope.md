# Engineering Scope and Non-Disclosure Boundary

## Included

This public companion includes only independently generated synthetic data and public-safe code demonstrating:

- schema validation;
- duplicate-key checks;
- missing-value checks;
- range checks;
- relational modeling;
- analytical marts;
- automated reporting;
- testing;
- CI;
- containerized execution.

## Excluded

The following remain in the private scientific repository and are not required to run this companion:

- manuscript and supplements;
- real/canonical analytical datasets;
- exact empirical variable construction;
- private model specifications;
- bootstrap arrays and inferential results;
- canonical research hashes;
- historical worker logs;
- private seed manifests;
- restricted provenance;
- submission/reviewer materials.

## Claim ceiling

A passing public companion demonstrates that the public engineering code operates correctly on the supplied synthetic fixture. It does not reproduce, validate, or disclose the private scientific findings.
